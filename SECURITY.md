# Security policy

This repository holds the source of Muhammad Hassan's portfolio, a static site served from GitHub Pages at <https://muhammadhassan05.github.io/HassanDev>. It has no backend, forms, cookies or third-party scripts, but security reports are still very welcome.

## Supported versions

Only the current `main` branch, which is what the live site is built from, receives fixes.

## Reporting a vulnerability

Please report vulnerabilities privately by email to **<hassannawab898@gmail.com>**. Do not open a public issue or pull request for a security problem.

Include as much of this as you can:

- what the issue is and where it is (URL, file or dependency)
- steps to reproduce, or a proof of concept
- the impact you think it has

I aim to acknowledge reports within 7 days. Once the issue is confirmed, it will be fixed and you will be told when the fix is live. If you would like to be credited, say so in your report.

## Scope

In scope: this repository's code, its build and CI configuration, and the deployed site.

Out of scope: third-party websites the site links to (for example LinkedIn, GitHub, Behance or Calendly), and denial-of-service against GitHub Pages itself.
